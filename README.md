## Project Description

**Impossible Runner 3D** is a funny and tricky 3D running game where the player has to run, avoid obstacles, and reach the finish line.

But there is one major twist — **the controls are reversed!**

If the player presses **Right**, the character moves **Left**, and if the player presses **Left**, the character moves **Right**.

The purpose is to make a simple running game unexpectedly confusing, funny, and challenging.

---

## The Problem (that doesn't exist)

Normal running games are too easy because the controls behave exactly as expected.

So we decided to solve a completely unnecessary problem:

> **What if a running game deliberately made the controls confusing? 😂**

---

## The Solution (that nobody asked for)

We created **Impossible Runner 3D**, where the player's horizontal movement is reversed.

For example:

* Press **Right** → Character moves **Left**
* Press **Left** → Character moves **Right**

This simple change turns an ordinary running game into a funny and surprisingly difficult challenge.

# How the Game Works

1. The player starts running.
2. Obstacles appear in the path.
3. The player uses the keyboard to control movement.
4. The controls are intentionally reversed.
5. The player must mentally adjust to the reversed movement.
6. The goal is to avoid obstacles and reach the finish.

### The Main Twist

**Your brain says RIGHT.
The game says LEFT. 😂**
